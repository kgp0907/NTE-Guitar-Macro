## 1.4.5 화면 개선

공유 신청 창을 세로로 늘리고, 작은 화면에서도 아래 신청·취소 버튼이 보이도록 배치를 조정했습니다. [변경 및 검증 결과](docs/VALIDATION-v1.4.5-KR.md)를 확인하세요.

## 주요 기능

- 가수·제목·버전·추천 톤·단축키를 나눈 곡 목록과 검색·즐겨찾기
- MIDI 트랙·채널별 주선율 / 보조 선율 / 화음·리듬 / 저음·베이스 / 제외 지정
- 파트별·편곡 미리 듣기, 편곡 프리셋, 화음 수 제한과 음역 보정
- 재생 막대의 원하는 곳을 클릭해 이동하고 그 위치부터 이어 연주
- 길게 누르는 음과 빠른 연타의 누름·해제 간격 보정
- 미니 HUD의 재생/이어하기 · 일시정지 · 정지 버튼 분리, 문구가 바뀌어도 너비·위치 고정
- 곡 정보 수정, 삭제·복원, 한국어·영어·일본어·중국어 UI
- 허용된 공유곡 온라인 연주, 파일 추가 허용곡의 `.nteplay` 수신과 오프라인 단축키 연주
- 곡 오른쪽 클릭 → **단축키 변경**, 중복 즉시 안내와 빈 키 버튼
- 언제든 **F8 긴급 정지**

## 처음 실행하기

1. [Releases](https://github.com/kgp0907/NTE-Guitar-Macro/releases)에서 **NTE-Guitar-v1.4.5-Windows.zip**을 받습니다.
2. ZIP을 **모두 압축 풀기** 합니다. `NTE-Guitar.exe`, `_internal`, `songs`, `sources`를 함께 보관하세요.
3. 게임의 기타 연주 화면을 열고 기본 음표 키 배치를 사용합니다. **NumLock**을 켜세요.
4. `NTE-Guitar.exe`를 실행하고 곡을 고릅니다. 추천 톤은 게임에서 직접 선택합니다.
5. **게임은 화면 앞에 두고**, 프로그램만 최소화하거나 미니 HUD를 사용합니다.
6. 목록의 곡 단축키를 누르면 처음부터 연주합니다. 언제든 **F8**로 정지합니다.

**기존 사용자는 업데이트 ZIP을 사용하세요.** 트레이에서 프로그램을 완전히 종료하고 기존 폴더를 백업한 다음, 업데이트 ZIP 안 `NTE-Guitar` 폴더의 내용을 기존 폴더에 병합합니다. `NTE-Guitar.exe`와 `_internal`을 함께 교체하세요. 기존 폴더와 `songs`, `sources`, `settings.json`, `ui-state.json`을 삭제하지 마세요. 신규 설치 ZIP의 기본 곡·설정을 기존 사용자 폴더에 덮어쓰지 마세요.

## 기본 단축키

| 키 | 동작 |
|---|---|
| Num1~9 | 가수 순 목록의 1~9번째 곡 |
| Ctrl+Num1~9 | 10~18번째 곡 |
| Alt+Num1~9 | 19~27번째 곡 |
| Ctrl+Alt+Num1~2 | 28~29번째 곡 |
| F6 | 선택한 곡의 현재 위치부터 연주·재개 |
| Num . | 일시정지·재개 |
| Num0 / F8 | 정지 · F8은 고정 긴급 정지 |
| F9 | 미니 HUD 표시·숨기기 |
| F10 | 전체 창 열기 |

Num은 **키보드 오른쪽 숫자패드**입니다. 위쪽 숫자열과 다릅니다. 영문 가수는 알파벳 순, 한글 가수는 가나다순으로 묶었고, 같은 가수 안에서는 톤·제목·버전 순으로 정렬했습니다. [전체 곡별 키 표](docs/SONGS.md)에서 확인할 수 있습니다.

청춘 콤플렉스는 **기타 중심 / 합주** 두 편곡을 모두 유지했습니다. 정렬을 바꿔도 이미 저장한 단축키가 자동으로 바뀌지는 않습니다.

## 원하는 부분부터 연주하기

곡을 고른 뒤 재생 막대의 빈 곳을 클릭하거나 손잡이를 끌어 위치를 정합니다. 게임으로 돌아와 **F6**을 누르면 그 위치부터 시작합니다. 곡별 단축키는 처음부터 시작하므로 중간 재개에는 F6을 사용하세요.

## 공유곡 추가·오프라인 연주

**공유 곡 보기 → 파일 추가 허용 곡 → 내 곡에 추가**로 받은 뒤 곡을 우클릭해 단축키를 지정합니다. 원본 MIDI 대신 저장된 최종 연주 결과만 담은 `.nteplay` 파일을 받으며, 인터넷 없이 기존 곡 목록에서 연주합니다. 원본 파트 재편곡과 MIDI 내보내기는 제공하지 않습니다. 온라인 연주만 허용된 곡은 파일 추가 버튼이 비활성화됩니다.

## 미니모드에서 잠시 멈추기

**일시정지**는 위치를 유지하며, **이어하기**를 누르면 그곳부터 계속 연주합니다. 기본 **Num .**도 일시정지·재개입니다. **F8/정지**는 완전 정지로, 로컬 곡은 처음으로 돌아갑니다. 온라인 전용 곡은 완전 정지 시 세션이 정리되므로 공유창에서 다시 불러오세요.

세 버튼은 처음부터 현재 언어의 가장 긴 문구가 들어갈 만큼 같은 너비를 확보합니다. 글자가 바뀌어도 옆 버튼이 움직이지 않습니다.

## MIDI 추가·편집

**곡 추가**에서 `.mid` / `.midi`를 고릅니다. 가수·제목·추천 톤을 입력하고 파트를 하나씩 들어보세요. 리드 기타는 주선율, 보컬 선율은 보조 선율, 리듬 기타는 화음·리듬으로 지정하는 방식부터 시작하면 편합니다. 저장한 뒤 목록에서 오른쪽 클릭 → **단축키 변경**으로 바로 키를 지정합니다.

원본 MIDI를 보관한 동봉 편곡은 9개입니다. 나머지는 저장된 음표 레이어를 바탕으로 편집하며 원래 악기 트랙이나 제외한 파트를 되살리지는 못합니다. 새로 추가하는 MIDI는 프로그램 안에 원본 사본을 보관하므로 다른 PC에서도 다시 편집할 수 있습니다.

PC 미리 듣기는 MIDI 소리여서 게임 소리와 다릅니다. 게임에서는 모든 파트가 선택한 기타 톤으로 나오며 실제 드럼 음색, 연속 벤딩·슬라이드·비브라토를 그대로 재현하지는 않습니다.

## 단축키 바꾸기

1. 곡을 **오른쪽 클릭 → 단축키 변경**합니다.
2. 원하는 키를 누르거나 아래 **사용 가능한 키**를 고릅니다.
3. 사용 중이면 어느 곡·기능이 쓰는지 즉시 표시되고 저장이 비활성화됩니다.
4. 기본 키에 자리가 없으면 Ctrl·Alt 조합으로 바꾸고 저장합니다.

전체 단축키 설정에도 실시간 중복 검사와 **빈 키 찾기**가 적용됩니다. F8은 긴급 정지 전용입니다.

## 배포 구성

이 공개 저장소와 배포 ZIP에는 프로그램 원문 소스와 수정 스크립트를 포함하지 않습니다. 실행파일, 사용자 안내와 스크린샷을 배포합니다. `sources/` 폴더에는 편곡용 원본 MIDI 자료가 들어 있습니다.

실행 ZIP에는 누적 Fix5가 적용된 **NTE-Guitar.exe 하나**만 넣었습니다. 실행에는 Windows 10/11 x64가 필요하며, PC 부하·게임 포커스·게임의 키 입력 처리에 따라 결과가 달라질 수 있습니다. 게임 파일·메모리를 수정하는 도구는 아닙니다.

현재 실행파일은 서명되지 않았습니다. 알 수 없는 게시자 경고는 악성코드 검사 결과와 다릅니다. 배포 출처와 SHA-256 값을 확인하세요. 의존 라이브러리 라이선스는 ZIP의 `licenses/`, 곡별 제작자와 출처는 악보 메타데이터와 [출처 목록](docs/CREDITS.md)에 보관했습니다.
