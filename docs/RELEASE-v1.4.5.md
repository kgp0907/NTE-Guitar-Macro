# NTE Guitar v1.4.5 · 공유 신청 창 높이 개선

공유 신청 창의 기본 높이를 **700 → 820픽셀**로 늘렸습니다. 작은 화면에서는 창 전체를 작업 영역 안에 맞추고, 아래 신청 내역·취소·공유 신청 버튼은 고정합니다. 입력 내용은 폼 내부에서 스크롤할 수 있습니다.

## 다운로드

- **기존 사용자:** [업데이트 ZIP · 곡·설정 유지](https://github.com/kgp0907/NTE-Guitar-Macro/releases/download/v1.4.5/NTE-Guitar-v1.4.5-Update-Windows.zip)
- **처음 설치:** [신규 설치 ZIP · 기본 29곡](https://github.com/kgp0907/NTE-Guitar-Macro/releases/download/v1.4.5/NTE-Guitar-v1.4.5-Windows.zip)

프로그램을 완전히 종료하고 업데이트 ZIP을 기존 폴더에 합쳐 적용하세요. 기존 폴더와 곡·설정 파일을 삭제하지 마세요.

소스·최종 EXE 각각 9종 검사, 네 언어·세 Tk 배율·두 화면 높이의 24가지 배치, ZIP 무결성과 기존 사용자 파일 보존 검사를 통과했습니다. 실제 게임 입력·청음과 실제 디스플레이 DPI 변경은 검사 범위에 포함하지 않습니다. 연주 엔진과 온라인 서버는 변경하지 않았으며, 1.4.4의 첫 실행 설정 저장 수정도 포함합니다.

[이전 릴리스](https://github.com/kgp0907/NTE-Guitar-Macro/releases) 다운로드는 그대로 유지합니다.
