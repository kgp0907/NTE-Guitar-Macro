# NTE Guitar 1.4.3 검증 결과

- 소스와 최종 EXE 각각 기존 9종 검사 통과.
- 미니모드 네 언어 × 세 크기의 기존 배치 검사 통과.

- 실제 게임 키 입력·스피커 청음·실제 디스플레이 DPI 변경 검사는 수행하지 않음.
