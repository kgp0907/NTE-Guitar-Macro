# NTE Guitar 1.4.5 · 공유 신청 창 높이 개선

- 공유 신청 창의 기본 높이를 700 → 820픽셀로 늘렸습니다.
- 작은 화면에서는 Windows 제목 표시줄·테두리를 포함한 창 전체를 작업 영역 안으로 맞춥니다.
- 신청 내역·취소·공유 신청 버튼은 아래에 고정하고 입력 폼만 스크롤합니다.
- 네 언어 × 세 Tk 배율 × 두 작업 영역 높이, 총 24가지에서 창이 화면 안에 있고 세 버튼이 보이는지 확인했습니다.
- 소스·최종 EXE 각각 기존 9종 검사 통과. 최종 EXE의 Python 모듈 75개가 소스와 일치합니다.
- 신규 설치 기본 29곡·원본 MIDI 9개·설정 보존, 업데이트 ZIP 사용자 파일 18종 보존 검사를 통과했습니다.
- 실제 디스플레이 DPI 변경·게임 키 입력·청음은 검사하지 않았습니다.

기존 사용자는 프로그램을 완전히 종료한 후 업데이트 ZIP을 기존 폴더에 합쳐 적용하세요. 곡·원본 MIDI·설정은 유지됩니다. 처음 설치할 때는 신규 설치 ZIP을 사용하세요. 이전 버전 다운로드도 유지합니다.
