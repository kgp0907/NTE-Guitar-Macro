# NTE Guitar 1.4.5 · 공유곡을 내 목록에 추가하기

파일 저장까지 허용된 공유곡을 원본 MIDI 없이 받아 기존 곡 목록에서 사용할 수 있습니다. 추가한 뒤에는 인터넷 없이 단축키·재생·일시정지·정지·위치 이동·배속·HUD를 사용합니다.

## 기존 사용자 업데이트

프로그램을 종료한 뒤 **Update-Windows.zip**을 기존 프로그램 폴더에 적용하세요. 동봉한 업데이트 안내를 따라 `NTE-Guitar.exe`와 `_internal`을 같은 버전으로 교체합니다. 업데이트 ZIP에는 개인 곡과 설정을 넣지 않았습니다. `songs`, `sources`, `settings.json`, `ui-state.json`을 지우지 마세요.

**Windows.zip**은 새 설치용이며 기본 29곡을 포함합니다. 기존 사용자 폴더에 기본 곡·설정을 덮어쓰는 용도로 사용하지 마세요.

## 공유곡 추가

1. 프로그램의 **공유 곡 보기**를 누릅니다.
2. **파일 추가 허용**으로 표시된 곡을 선택합니다.
3. **내 곡에 추가**를 누릅니다. 원본 MIDI·편집용 파트 없이 연주 결과만 저장합니다.
4. 기존 곡 목록에서 추가된 곡을 우클릭해 **단축키 변경**으로 원하는 키를 지정합니다. 사용 중인 키와 긴급 정지 F8은 중복 지정할 수 없습니다.
5. 이후 인터넷 연결을 끊어도 기존 곡처럼 연주할 수 있습니다. 게임 연주는 이환의 기타 화면에서 사용하세요.

같은 곡의 같은 연주 데이터를 다시 추가하면 중복 저장하지 않고 기존 곡을 선택합니다. 새 개정판은 별도 곡으로 추가하므로 기존 파일과 단축키를 덮어쓰지 않습니다. 삭제한 곡은 기존 삭제곡 복원 기능을 이용합니다.

**온라인 연주만** 표시된 곡은 미리 듣기·게임 연주를 사용할 수 있으며 파일 추가 버튼은 비활성화됩니다. 파일 추가 허용 여부는 운영자가 곡별로 관리합니다.

## 연주용 파일 .nteplay

- 포함: 곡명·가수·편곡자 등 공개 정보, 최종 음높이·시작 시각·음 길이·연주 타이밍.
- 미포함: 원본 MIDI, 원본 기타·피아노 등의 편집용 파트, 비공개 제출 근거, 관리자 정보.
- 내 목록의 데이터는 `songs/<번호>.json`, 받아 둔 연주용 파일은 `sources/playback/*.nteplay`에 보관합니다.
- **곡 추가 → 공유 파일 가져오기**에서 `.nteplay` 파일을 다시 가져올 수 있습니다.
- 추가한 연주용 곡에서 **공유 파일 내보내기**를 누르면 원본 없는 `.nteplay` 파일을 저장합니다.
- 파트 재편곡·원본 MIDI 내보내기·공유 신청용 원본 재생성은 제공하지 않습니다. 곡 정보·단축키·즐겨찾기 관리는 사용할 수 있습니다.

공유 서버가 나중에 파일 제공을 중단해도 이미 저장한 파일을 원격 삭제하지 않습니다. 이 형식은 DRM이나 음악의 이용 허락을 대신하는 기능이 아닙니다. 파일의 실제 이용·재공유는 허락받은 범위에 맞춰야 합니다.

## 운영자

온라인 공개 승인과 파일 저장 허용을 구분합니다. 기존 승인곡은 자동으로 다운로드 허용되지 않습니다. 관리자 화면에서 **연주용 파일 저장·오프라인 이용까지 허용된 곡**에 체크하고 해당 근거를 남긴 뒤 **오프라인 제공 설정 저장**을 누릅니다. 새 연주 개정판을 게시할 때도 파일 제공 범위를 다시 확인합니다.

## 확인 범위

자동 검사에서는 실제 게임 키 입력과 스피커 출력을 보내지 않습니다. 해당 항목은 사용자가 실제 게임에서 확인해야 합니다. 설치된 구버전을 자동 종료하거나 개인 곡·설정을 교체하지 않았습니다.
