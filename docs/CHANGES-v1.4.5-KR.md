# 첫 배포 이후 변경 내역 · 1.4.5

2026-10-24. 보관된 v1.0 실행파일과 현재 소스, 검사 결과를 비교한 내용입니다.

## 1.4.5 공유 신청 창 높이 조정

공유 신청 창의 기본 높이를 700에서 820픽셀로 늘렸습니다. 신청 내역·취소·공유 신청 버튼은 폼 아래에 고정하고, 작은 화면에서는 창 테두리와 제목 표시줄을 포함해 작업 영역 안으로 높이를 맞춥니다. 입력 내용은 폼 내부에서 스크롤합니다.

기존 곡·설정, 연주 엔진과 온라인 서버는 변경하지 않습니다.

## 1.4.4 첫 실행 설정 저장 오류 수정

설정 파일이 없는 빈 폴더에서 처음 실행하고 공유곡 또는 MIDI를 추가한 뒤 재실행하면, 단축키 설정과 정상 백업이 없다는 경고가 뜨던 문제를 수정했습니다. 첫 실행 때 기본 재생·일시정지·정지 키와 비어 있는 곡 단축키 설정을 파일로 저장하고 정상 백업도 만듭니다. 새로 추가한 곡의 단축키는 직접 지정합니다.

기존 곡이나 설정·백업·원본 자료가 있는 폴더에는 초기값을 강제로 덮어쓰지 않습니다. 실제 손상 설정 복구 보호를 유지하며, 파일이 없는 경우와 손상된 경우의 안내를 구분합니다. 동시에 다른 프로세스가 만든 설정 파일도 덮어쓰지 않습니다. 이미 경고가 발생한 폴더에서 정상 백업이 전혀 없다면 기존 경고의 확인 후 단축키 설정에서 원하는 키를 저장해야 합니다. 수정본이 잃어버린 과거 단축키를 추측해서 복원하지는 않습니다.

## 1.4.3 미니모드 버튼 너비 고정

재생·이어하기·전환 대기·공유곡 준비 등 상태별 문구가 바뀌어도 버튼 크기와 옆 버튼 위치가 움직이지 않습니다. 현재 언어의 가장 긴 문구를 실제 글꼴로 측정해 처음부터 세 버튼에 같은 너비를 확보합니다. 글자는 가운데에 표시하며, 언어 또는 HUD 크기를 바꿀 때만 너비를 다시 계산합니다.

## 버그 수정

- **단축키 설정 보호**: 설정 파일이 손상되면 최근 정상 백업과 이전 백업에서 복구합니다. 손상 원본을 보존하고, 복구할 수 없을 때 곡 단축키를 임의로 재배정하거나 조용히 덮어쓰지 않습니다. 저장 도중 실패해도 기존 파일을 유지합니다.
- **중복 실행 처리**: 이미 실행 중이라는 안내를 띄울 때 불필요한 실행 잠금 핸들을 해제합니다. 안내 중 기존 프로그램이 종료된 뒤 재실행이 막히는 경우를 수정했습니다.
- **단축키 정렬**: F1·F2·F10과 숫자패드·조합키를 문자열 순서 대신 키 순서로 정렬합니다. 정렬 때문에 실제 단축키가 바뀌지는 않습니다.
- **미리 듣기와 공유창**: 공유창 미리 듣기의 중복 실행을 막고 완료·정지·오디오 오류 후 버튼을 복구합니다. 종료 시 취소와 장치 정리를 보강했습니다. 창을 닫은 뒤 도착한 응답이 곡을 추가하거나 재생을 시작하지 않도록 합니다.
- **공유곡 추가**: 같은 연주 파일을 여러 번 추가하면 기존 곡 위치로 이동합니다. 손상 파일과 잘못된 해시·경로·권한 정보를 거부하며, 개인 곡과 설정을 덮어쓰지 않습니다.
- **온라인 서버 백업**: 호스팅 내부 마이그레이션 표 때문에 정상 백업이 실패하던 경우를 수정했습니다. 실제 사용자 표 검증은 유지하고, 실패 단계 안내와 작업 잠금 해제를 보강했습니다.
- **작은 창·다국어 화면**: 공유 신청 폼과 창 아래 주요 버튼의 접근성, 긴 제목 표시와 입력 검증 안내를 보강했습니다.

## 1.4.2 미니모드 변경

미니 플레이어를 **재생/이어하기 · 일시정지 · 정지** 세 버튼으로 구분했습니다.

| 조작 | 동작 |
| --- | --- |
| 일시정지 | 현재 위치를 유지하고 누르고 있던 음표 키를 놓습니다. |
| 이어하기 | 멈춘 위치에서 계속 연주합니다. 게임이 앞에 없으면 전환을 기다립니다. |
| 전환 대기 중 일시정지 | 예약된 시작을 취소하고 위치를 유지합니다. |
| 정지 / F8 | 완전 정지합니다. 로컬 곡은 처음으로 돌아갑니다. |
| 일시정지 단축키 | 기본 `Numpad .`입니다. 기존 사용자 지정 키를 그대로 쓰며 미니모드에 현재 키를 표시합니다. |

전용 일시정지 버튼을 빠르게 여러 번 눌러도 재생으로 토글되지 않습니다. 일시정지 중에는 이어하기 버튼이 활성화되고, 연주 중에는 일시정지 버튼이 활성화됩니다. 온라인 전용 곡도 일시정지·이어하기가 가능하지만, 완전 정지하면 세션 데이터가 해제되어 공유창에서 다시 불러와야 합니다. 내 목록에 추가한 연주 파일은 일반 로컬 곡처럼 동작합니다.

## 추가 기능과 구분

온라인 공유 신청·검토·공개 목록, 원본 없는 온라인 연주, 허용곡의 `.nteplay` 파일 추가와 오프라인 단축키 연주는 첫 배포 이후 추가한 기능입니다. 단순 버그 수정과 구분합니다.

**키 누름·연타 간격 보정, 짧은 처리 지연 회복, F6 인식과 미리 듣기 클릭 보정은 v1.0의 Fix5에 이미 포함됐습니다.** 이번 업데이트에서 새로 고쳤다고 표기하지 않습니다. 연주 시각 계산·기본 악곡·편곡·개인 설정은 이번 미니모드 변경으로 바꾸지 않습니다.

## 설치와 검증 범위

기존 사용자는 프로그램을 완전히 종료하고 `NTE-Guitar-v1.4.5-Update-Windows.zip`의 내용을 기존 폴더에 병합하세요. 기존 폴더를 삭제하지 마세요. 신규 사용자는 `NTE-Guitar-v1.4.5-Windows.zip`을 사용합니다.

소스와 최종 EXE에서 연주·공유·설정 복구·온라인·신청·화면 배치·원격 세션·오프라인 파일 검사를 실행합니다. 미니모드의 일시정지 연속 클릭, 위치 유지·이어하기, 게임 전환 대기 취소, 완전 정지, 네 언어와 세 크기 배치를 포함합니다. 검증 요약은 함께 제공한 VALIDATION-v1.4.5.json에서 확인하세요. 실제 게임 입력과 스피커 청음은 자동 검사 범위에 포함하지 않습니다.
