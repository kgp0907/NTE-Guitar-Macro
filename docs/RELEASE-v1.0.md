# NTE-Guitar v1.0

Neverness to Everness Guitar Auto Player · Windows 10/11 x64

## Download / 다운로드

Download **NTE-Guitar-v1.0-Windows.zip**, extract all files, and run **NTE-Guitar.exe**. No Python installation required.

**NTE-Guitar-v1.0-Windows.zip**을 모두 압축 풀고 **NTE-Guitar.exe**를 실행하세요. Python 설치는 필요 없습니다.

## Included / 포함 내용

- Latest cumulative Fix5 executable only / 최신 Fix5 실행파일 하나
- 29 arrangements grouped by artist with sequential keypad hotkeys / 29곡 가수별 정렬·숫자패드 순차 배정
- MIDI import, part selection, PC preview, seeking, mini HUD and editable shortcuts
- Immediate shortcut-conflict feedback, available-key buttons, and right-click song shortcut editing
- English/Korean documentation, screenshots, song list and dependency notices

Default song keys: Num1–9 → Ctrl+Num1–9 → Alt+Num1–9 → Ctrl+Alt+Num1–2.

F6 resume · Num . pause/resume · Num0/F8 stop · F9 HUD · F10 main window.

Keep the game in the foreground with its guitar screen open and NumLock on. The game tone is selected manually. Windows builds are unsigned. Application source code and repair scripts are not included in this release.

See README_KR.md for Korean instructions and docs/SONGS.md for the complete key list. `SHA256SUMS.txt` contains the download checksum.


Packaging update: plain Python repair sources have been removed from the public ZIP. The executable and playback data are unchanged.

패키징 갱신: 공개 ZIP에서 Python 수정 소스를 제외했습니다. 실행파일과 연주 데이터는 동일합니다.
