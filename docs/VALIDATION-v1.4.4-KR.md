# NTE Guitar 1.4.4 · 첫 실행 설정 저장 오류 수정

설정 파일이 없는 빈 폴더에서 첫 실행 후 공유곡 또는 MIDI를 추가하고 재실행하면, 단축키 설정과 정상 백업이 없다는 경고가 뜨던 문제를 수정했습니다. 첫 실행 때 설정을 메모리에만 두고 파일로 저장하지 않았던 것이 원인이었습니다.

- 빈 폴더의 첫 실행에서 기본 재생·일시정지·정지 키와 비어 있는 곡 단축키 설정을 저장하고 정상 백업을 생성합니다.
- 공유곡·MIDI를 추가한 뒤 재실행하고, 키를 지정해 다시 실행해도 유지되는지 검사했습니다.
- 설정 저장 실패와 파일 누락을 구분해서 안내합니다.
- 실제 손상 파일·정상 백업 복구 보호를 유지하고, 다른 프로세스가 만든 설정도 덮어쓰지 않습니다.
- 기존 곡·설정·원본 MIDI·연주 엔진·서버는 변경하지 않습니다.

기존 사용자는 프로그램을 완전히 종료한 뒤 업데이트 ZIP을 기존 폴더에 병합하세요. 기존 폴더나 songs, sources, settings.json, ui-state.json을 삭제하지 마세요. 처음 설치할 때는 기본 29곡이 들어 있는 신규 설치 ZIP을 사용하세요.

**이미 1.4.3에서 경고가 발생한 테스트 폴더:** 설정 파일 자체가 생성되지 않았던 경우, 수정본 적용 후 단축키 설정에서 사용할 키를 한 번 저장해야 합니다. 기존 곡은 유지됩니다. 설정·백업이 없는 상태의 과거 단축키를 임의로 추측해 배정하지는 않습니다.

소스·최종 EXE 각각 9종 검사, 최종 EXE와 소스 75개 모듈 일치, ZIP 무결성, 기존 사용자 파일 18종 보존 검사를 통과했습니다. 실제 게임 입력·스피커 청음은 검사하지 않았습니다.
